# Queue Bot — очереди на сдачу лаб в Telegram

Telegram-бот для студенческих групп: создаёт очереди на сдачу лабораторных прямо в групповом чате, открывает запись по таймеру, позволяет меняться местами и уведомляет, когда твоё место сдвинулось.

## Возможности

- **Несколько очередей одновременно**: по разным предметам, в разных группах.
- **Единое время записи**: на пару в среду запись открывается во вторник в 00:00 и закрывается в среду в 23:59 — само, без участия ответственного.
- **Лист с номерами мест**: можно занять конкретное место («я 6») или первое свободное, перейти на другое свободное место. Ушедший освобождает место — остальные не двигаются.
- **Запись одногруппника**: можно записать ещё одного человека — выбрать из списка участников потока или вписать имя.
- **Обмен местами**: запрос из лички, вторая сторона подтверждает или отклоняет. Запрос действует 30 минут.
- **Уведомления**: если кто-то занял место впереди, вышел, перешёл или поменялся — все, чей номер по очереди изменился, получают сообщение в личку.
- **«Мои очереди»**: в личке видно все свои очереди, номер места, номер по очереди и за кем стоишь.
- **Расписание**: лабораторная вводится один раз (каждую неделю или раз в 2 недели) — очереди открываются сами. Накануне ответственному приходит напоминание с кнопкой «Пропустить».
- **Удаление очереди** ответственным; закрытые очереди удаляются сами через 7 дней.
- **Устойчивость к перезапуску**: всё хранится в SQLite, таймеры восстанавливаются при старте.

## Как пользоваться

### Ответственному

1. Добавь бота в групповой чат. Тот, кто добавил, становится ответственным.
2. **Расписание:** `/schedule` → «➕ Добавить лабораторную» → предмет, дата первой пары, повтор (каждую неделю / раз в 2 недели), до какого числа, число мест. Дальше бот сам открывает очереди и накануне в 18:00 спрашивает, не пропустить ли дату.
   **Разовая очередь:** `/newqueue` → название, дата пары, число мест.
3. Сообщение очереди с кнопками появится в группе.
4. Удалить очередь: `/deletequeue`.

### Студенту

1. Нажми «Start» у бота в личке — без этого бот не сможет присылать уведомления и запросы на обмен.
2. Под сообщением очереди в группе:
   - **✅ Записаться** (первое свободное место) / **🚪 Выйти**
   - **🔢 Выбрать место** — сетка свободных номеров
   - **👥 Записать одногруппника**
   - **📋 Мои очереди** — места, выход, обмен.

### Команды

| Команда | Где | Что делает |
|---|---|---|
| `/start` | личка | Начать работу, включить уведомления |
| `/myqueues` | личка | Мои очереди |
| `/schedule` | группа / личка | Расписание лабораторных (ответственный) |
| `/newqueue` | группа / личка | Разовая очередь (ответственный) |
| `/deletequeue` | группа / личка | Удалить очередь (ответственный) |
| `/cancel` | личка | Отменить ввод |
| `/help` | личка | Справка |

## Запуск

Нужен Python 3.13+.

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`), получи токен. Там же включи добавление в группы: `/setjoingroups` → Enable.
2. Установи зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt     # Windows
   # .venv/bin/python -m pip install -r requirements.txt           # Linux / macOS
   ```
3. Скопируй `.env.example` в `.env` и вставь токен:
   ```
   BOT_TOKEN=123456:ABC...
   TZ=Europe/Moscow
   DB_PATH=bot.db
   ```
4. Запусти:
   ```bash
   .venv\Scripts\python.exe main.py
   ```
   На Windows можно просто дважды щёлкнуть `start_bot.bat`.

Бот работает, пока запущен процесс. База (`bot.db`) и логи (`logs/bot.log`) создаются автоматически.

> **Запускай только одну копию бота** — две копии с одним токеном мешают друг другу (`TelegramConflictError`).

## Тесты

```bash
.venv\Scripts\python.exe -m pytest -q
```

Покрыта логика очереди: запись, выход, лимиты, права, обмен, устаревание запросов, получатели уведомлений, одновременные нажатия.

## Устройство

```
queue_bot/
├── main.py               # точка входа: бот, планировщик, логирование
├── config.py             # настройки из .env
├── middlewares.py        # сохранение пользователей и участников потоков
├── timeparse.py          # разбор дат и времени
├── keyboards.py          # клавиатуры и callback data
├── db/
│   ├── schema.sql        # таблицы
│   ├── database.py       # соединения, транзакции, write lock
│   └── repo.py           # запросы к БД
├── handlers/
│   ├── group.py          # групповые чаты и кнопки очереди
│   ├── private.py        # личка: мои очереди, запись одногруппника
│   ├── admin.py          # создание и удаление очередей
│   ├── schedule.py       # расписание
│   └── swap.py           # обмен местами
├── services/
│   ├── queue_service.py  # единственная точка изменения очередей
│   ├── permissions.py    # права
│   ├── notifier.py       # уведомления о сдвиге мест
│   ├── renderer.py       # сообщение очереди и его обновление во всех чатах
│   ├── planner.py        # расписание: автосоздание очередей, напоминания, очистка
│   └── scheduler.py      # открытие (накануне 00:00) и закрытие (23:59) по времени
└── tests/
```

Основные решения:

- **Очередь — лист с номерами мест** (`slot`, уникален в очереди, бывают пропуски). «Номер по очереди» вычисляется как порядок среди занятых мест.
- **Все изменения очереди идут через `QueueService`**: транзакция под общим write lock, запись в журнал `queue_events`, снимок «до/после».
- **Уведомления строятся по разнице номеров по очереди**, а не по типу операции — новые операции автоматически уведомят всех, кого затронули.
- **Миграции БД** выполняются при старте (`db/database.py`): база от старой версии обновляется без потери данных.
- **Права проверяются в одном месте** (`permissions.py`) — модерацию (удаление/перестановка участников ответственным) можно включить, не меняя остальной код.
- **Поток** — набор чатов с общими очередями. Сейчас один чат = один поток; «Мои очереди» показывают записи из всех потоков.
